# Free VPN Usage Demonstration

This project demonstrates how to use a reputable free VPN service securely. It covers installation, IP verification, browsing encryption, speed comparison, and a summary of VPN benefits and limitations.

## Steps Covered

1. Sign up for ProtonVPN (Free Tier)
2. Install and launch the VPN client
3. Connect to a server
4. Verify new IP via [whatismyipaddress.com](https://whatismyipaddress.com)
5. Test encrypted browsing
6. Disconnect and compare speed/IP
7. Document encryption & privacy features
