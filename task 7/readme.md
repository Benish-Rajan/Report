# 🔍 Browser Extension Audit

This project documents a basic audit of browser extensions to improve security and performance.

## 📋 Steps Taken

1. Opened browser's extension/add-ons manager.
2. Reviewed all installed extensions.
3. Checked permissions and user reviews for each extension.
4. Identified unused or suspicious extensions.
5. Removed suspicious or unnecessary ones.
6. Restarted browser to check for improvements.
7. Researched how malicious extensions harm users.
8. Documented the results with screenshots and a report.

## 📁 Files Included

- `audit-report.md` - Detailed steps and results.
- `screenshots/` - Screenshots of the process.

## 🔐 Key Takeaways

- Regular audits help protect against spyware and performance slowdowns.
- Extensions with broad permissions and low reviews pose risks.
